# About the breakouts

Breakout rooms allow Instructors to split a Live Hub session into smaller groups. Learners join these rooms for discussions, activities, or collaboration, and automatically return to the main session when the activity ends. Breakout rooms are useful for brainstorming, group activities, and focused learning.

Instructors can create and manage breakout rooms, assign learners, and guide activities using instructions. During the session, Instructors can monitor room activity, view real-time discussion summaries, and provide support when needed.

Learners collaborate within their assigned rooms, participate in discussions, and stay aligned with the activity using shared instructions and summaries.

After the session, Instructors can review breakout discussions and outcomes through session reports and the Session dashboard, enabling better analysis and follow-up.

## Benefits of breakout sessions

* **Encourages collaboration**:Participants can collaborate in smaller groups for focused discussions and activities.

* **Real-time room visibility**: Instructors can monitor engagement, participation, and help requests across rooms without interrupting participants.

* **AI-powered discussion insights**: Real-time summaries help Instructors quickly understand discussions across rooms and guide activities effectively.

* **Structured activity guidance**: Provide instructions to guide learners during breakout activities.

* **Flexible participant management**: Participants can be assigned and adjusted easily to support different learning formats.

* **Post-session insights and reporting**: Instructors can review summaries, reports, and session data in the Session dashboard to analyze outcomes and improve future sessions.

## Breakout session terminology

These terms explain how breakout sessions work and how participants interact during activities.

| **Term** | **Description** |
|----|----|
| **Breakout session** | A temporary session in a Virtual Classroom where participants are divided into smaller groups for focused discussions or activities. |
| **Breakout room** | These are smaller groups within a breakout session where learners are divided to participate in a specific activity. |
| **Breakout instructions** | The instructor assigns the task or discussion to participants in a breakout room. |
| **Breakout report** | A measure of a learner's engagement during a breakout session, used by Instructors to monitor and evaluate participation levels. |

## Breakout session workflow

Breakout session follow a structured flow that includes setup, live collaboration, and session completion.

### Set up breakout session

Before starting a breakout session, Instructors create and configure breakout rooms according to the session's requirements.

* Define the number of breakout rooms.

* Assign learners to rooms automatically or manually by dragging and dropping participants.

* Add activity instructions to guide learners.

This setup ensures that learners are organized and aligned with the activity before the session begins.

### During the breakout session

Once the breakout session starts, learners are moved to their assigned rooms to collaborate on the given activity.

* Learners interact and participate within their breakout rooms.

* Instructors can monitor room activity, track participation, and respond to help requests.

* Instructors can view real-time summaries of discussions and join rooms to guide learners when needed.

This phase focuses on collaboration and active participation.

### After the breakout session

When the breakout session ends, all participants are automatically moved back to the main room.

* Learners return to the main session view.

* Instructors can review overall activity, outcomes, and session summaries through the reports.

* Instructors can create a duplicate session to reuse the same setup for future activities.

This marks the completion of the breakout activity and enables post-session review.
