# Use the Chat panel as an Instructor in Live Hub

As an Instructor, the Chat panel is your hub for managing communication during a Live Hub session. From a single panel, you can follow the public discussion, hold private conversations, and review the questions that AI detects from the chat. You can also moderate the conversation and respond with AI assistance.

This article walks through the actions available to Instructors in the Chat panel, from accessing the panel to managing messages and settings.

## Access the Chat panel

Use the Chat panel to manage conversations, respond to learners, and monitor questions during a session. The panel provides access to public, private, and question-based discussions in one place.

Follow these steps to access the Chat panel:

1.  Join the Live Hub session.

1.  Select the Chat ![Chat Panel Icon Instructor](assets/chat-panel-icon-instructor.png "Chat panel icon.") icon from the control bar. The Chat panel opens with the **Everyone** tab selected by default, allowing you to start or join an ongoing conversation.

1.  Select one of the following as needed:

    1.  Everyone

    1.  Private

    1.  Questions

    ![Chat Panel Everyone Tab](assets/chat-panel-everyone-tab.png "The Chat panel opens to the Everyone tab, where you can follow the public conversation and switch to the Private and Questions tabs.")

1.  Type your message and select **Send**.

## Chat panel settings

The Chat panel provides options to manage conversations and customize your chat experience during a session. You can clear messages, control notifications, and adjust text size as needed.

![Chat Panel Settings Menu](assets/chat-panel-settings-menu.png "Chat panel settings menu.")

The following options are available from the chat panel settings:

| **Option** | **Description** |
|----|----|
| **Clear all chats** | Removes all messages from the chat panel. |
| **Disable chat notifications** | Turns off chat notifications for the session. |
| **Text size** | Adjusts the size of chat messages for better readability. The available options are **Small**, **Medium**, and **Large**. |

## Reply to chat messages

The reply feature allows you to respond directly to a specific message, helping maintain context during discussions and making conversations easier to follow.

To reply to a message in the chat:

1.  Hover over the message you want to respond to.

1.  Select **Reply**.

    ![Reply To Chat Message](assets/reply-to-chat-message.png "Select Reply on a message to respond to it directly and keep the conversation in context.")

1.  Enter your response in the message input field.

1.  Select **Send**.

The reply displays a snippet of the original message alongside your response, helping participants understand the conversation's context.

### React to a message

You can also react to messages to quickly acknowledge or respond without typing a reply. Hover over a message and select a reaction. The selected reaction appears below the message and is visible to other participants in the chat.

![Chat Message Reaction](assets/chat-message-reaction.png "A reaction appears below the message and is visible to everyone in the chat.")

## Edit the chat messages

The edit message feature allows you to update a message after sending it, helping you correct or refine your response.

To edit a message in the chat:

1.  Hover over the message that you want to edit.

1.  Select **Edit**.

    ![Edit Chat Message](assets/edit-chat-message.png "Select Edit to update a message you've already sent.")

1.  Update the message in the input field.

1.  Select **Save** to apply the changes or **Cancel** to discard them.

The updated message replaces the original message in the chat and is marked as **Edited**.

## Mention learners in the chat messages

The tagging feature in the Chat panel allows you to address a specific learner directly during a session. Using tags draws attention to your message and improves visibility for the learner you mention, especially during active discussions.

To mention a learner in the chat:

1.  In the message input field, type **@**.

1.  Select the participant's name from the list.

    ![Mention Learner In Chat](assets/mention-learner-in-chat.png "Type @ to populate the list of participants and select the name from the list.")

1.  Enter your message.

1.  Select **Send**.

The tagged learner receives a notification, and their name is highlighted in the message for better visibility.

## Start a private chat

The **Private** tab in the chat panel allows you to have private messages without interrupting the public discussion. You can start a new chat, continue existing conversations, or communicate with specific learners.

To start a private chat:

1.  Select the **Private** tab. A list of participants appears.

    ![Start Private Chat](assets/start-private-chat.png "The Private tab lists participants so you can message Instructors only or an individual learner.")

1.  You can do the following:

    1.  Select **Instructors only** at the top of the list to send messages to other Instructors. Messages are visible only to Instructors.

    1.  Select an individual learner to start a private conversation.

1.  Type your message and select **Send**. Messages are visible only to you and the selected participant.

### Disable private chat for Learners

By default, learners can chat privately with other participants. As an Instructor, you can control whether learners can use private chat during a session.

To disable private chat for learners:

1.  Open **Room settings**.

1.  Select **Participant permissions**.

    ![Disable Private Chat Learners](assets/disable-private-chat-learners.png "Turn off Send private messages in Participant permissions to stop learners from chatting privately.")

1.  Disable **Send private messages**.

1.  Select **Done**.

Once disabled, Learners will no longer be able to start or participate in private conversations.

## Draft replies to learner questions with AI

The **Questions** tab helps Instructors manage and respond to learner questions more efficiently. AI automatically detects questions from the chat and provides suggested responses to assist Instructors during the session.

To generate an AI-assisted reply:

1.  Navigate to the **Questions** tab.

1.  Hover over the detected question.

1.  Select **Draft reply using AI**.

    ![Draft Ai Chat Reply](assets/draft-ai-chat-reply.png "Select Draft reply using AI to generate a suggested response to a detected question.")

1.  (Optional) Review and edit the suggested response.

1.  Select **Send**.

The AI-generated reply is added to the chat and can be modified before sending to ensure accuracy and relevance.

### Upload files for better responses

You can also upload reference files to improve the accuracy and relevance of AI-generated responses.

To upload a file:

1.  Navigate to the upper right corner of the Chat panel.

    ![Open File Upload Chat](assets/open-file-upload-chat.png "Open Upload content references to add files that help AI generate more accurate responses.")

1.  Select **Upload content references**. A pop-up window of **QnA reference content** appears.

1.  Select **Browse files**.

    ![Browse Files Chat](assets/browse-files-chat.png "Select Browse files in the QnA reference content window to upload a reference file from your system.")

1.  Upload the file from your system.

AI uses the uploaded content to generate more accurate and relevant responses to questions in the **Everyone** tab.

## Delete messages

The delete message option allows you to remove messages from the chat to keep discussions focused and relevant. You can delete your own messages that are not relevant to the topic or are disruptive to the discussion.

![Delete Chat Message](assets/delete-chat-message.png "Delete your own messages to keep the discussion focused and relevant.")
