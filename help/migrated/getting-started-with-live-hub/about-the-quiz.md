# About the Quiz feature in Live Hub

The Quiz feature in a Live Hub allows Instructors to create and conduct quizzes to assess learner understanding during a live session. You can create quizzes before or during the session, launch them to collect responses in real time, and monitor results as learners respond in the Session dashboard.

>[!NOTE]
>
> Quizzes in a Live Hub session differ from those created in the **Quiz Creation tool** in Adobe Learning Manager.

## Key benefits

The Quiz feature provides the following benefits:

* **Evaluate learning outcomes**: Assess how well learners have understood and retained key concepts after instruction.

* **Conduct structured assessments**: Create multi-question quizzes to evaluate learners across a topic or module, beyond single-question checks.

* **Track individual performance**: Live quiz results help Instructors quickly understand how the entire group is performing and identify areas that may need further clarification.

* **Improve engagement**: Encourage active participation through interactive assessments.
