# Role of Administrator in Live Hub session

As an Administrator in Adobe Learning Manager (ALM), you can configure and manage key components required for delivering Live Hub training. These capabilities help streamline Instructor assignments, course setup, branding, and reporting.

This article provides a high-level overview of Administrator actions related to Live Hub sessions. For detailed configuration steps and workflows, refer to the linked articles in each section.

## Administrator capabilities for Live Hub

As an Administrator, you can set up and run Live Hub training using the capabilities below. Select a linked article for detailed steps.

| **Capability** | **What you can do** | **Learn more** |
|----|----|----|
| **Enable Live Hub** | Enable Live Hub for the Adobe Learning Manager account. You can also enable AI-powered assistants that support Authors and Instructors during Live Hub sessions, including: <ul><li>Poll Assistant</li><li>Q&A Assistant</li><li>Breakout Monitoring Assistant</li><li>Recording Topics Generator</li><li>Instructor Finder Assistant</li></ul> | [Enable Live Hub feature](../administrators/feature-summary/enable-live-hub.md) |
| **Manage Instructor profiles** | <ul><li>Define Instructor roles and responsibilities</li><li>Assign skills and expertise</li><li>Set availability and teaching preferences</li><li>Enable smarter recommendations through Instructor Finder</li></ul> | [Add and manage Instructors](./instructor-management.md) |
| **Add bulk skills** | <ul><li>Add skills in bulk</li><li>Organize and update skill sets</li><li>Align skills with course requirements</li></ul> | [Create and modify skills and levels](../administrators/feature-summary/skills-levels.md#add-skills-in-bulk) |
| **Manage holidays** | <ul><li>Add a single holiday, or import several at once by uploading a CSV file</li><li>Set a date, name, and optional description for each holiday</li><li>Review, search, and filter holidays across the All, Upcoming, and Past tabs</li><li>Maintain one consistent, account-wide holiday calendar</li></ul> | [Manage holidays](./manage-holidays.md) |
| **Configure branding and color themes** | <ul><li>Apply color themes</li><li>Maintain a consistent visual identity across sessions</li><li>Enhance the learner experience with branded environments</li></ul> | [Color themes](../administrators/feature-summary/themes.md#color-themes) |
