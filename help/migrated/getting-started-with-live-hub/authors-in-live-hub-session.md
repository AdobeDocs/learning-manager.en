# Role of Authors in Live Hub session

As an Author in Adobe Learning Manager, you create and manage Virtual Classroom courses that use Live Hub to deliver live, Instructor-led training. You set up the course, configure the session, assign instructors, and publish it so that the session is ready to run.

This article describes what an Author does when working with Live Hub.

## What Authors can do

As an Author, you are responsible for the following tasks when creating a Live Hub course.

### Create Live Hub courses

Authors can create Live Hub courses during the course creation workflow. You can:

* Add a Virtual Classroom module to the course.
* Choose Live Hub as the Live Virtual Training Tools.
* Define session details like title, description, and duration.

### Configure session details

Authors can define how the Live Hub session will be conducted. You can:

* Set date, time, and time zone
* Configure session duration

### Use Instructor Finder to assign Instructors

Use Instructor Finder to find and assign instructors based on the course type. You can:

* Get AI-powered instructor recommendations based on course requirements, skills, and availability.
* Select one or more qualified instructors for the session.
* Speed up course setup with intelligent recommendations and simplified instructor assignment.

### Publish and manage courses

Once configured, authors can finalize and manage course delivery. You can:

* Publish the course for learners
* Update session details if required
* Manage course structure and modules

View [Create a Live Hub session](./create-a-live-hub-session.md) for more information.
