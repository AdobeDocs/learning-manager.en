# Use the Chat panel as a Learner

Use the Chat panel to participate in conversations during a Live Hub session. You can send messages to all participants, ask questions, and manage your chat messages. If your Instructor has enabled private messaging, you can also chat directly with other participants. This article describes the chat features available to Learners.

## Access the Chat panel

As a Learner, you can use the Chat panel to participate in discussions, ask questions, and connect with others during a session.

Follow these steps to access the Chat panel:

1.  Join the Live Hub session.

1.  Select ![open-chat-panel](./assets/open-chat.svg)  from the control bar. The Chat panel opens with the **Everyone** tab by default, allowing you to join or follow the ongoing conversation.

1.  Select one of the following tabs:

    1.  Everyone

    1.  Private

    ![Chat Panel Tabs](assets/chat-panel-tabs.png)
    *Chat panel showing the Everyone and Private tab for communication.*

1.  Type your message and select **Send**.

## Customize the Chat panel

You can customize the Chat panel to manage notifications and improve message readability during a Live Hub session.

To customize the Chat panel:

1.  Open the **Chat** panel.

1.  Select **More options (⋯)** in the upper-right corner of the Chat panel.

1.  Select one of the following options:

    1.  **Turn off notifications**: Disable chat notifications for the current session.

    1.  **Change text size**: Increase or decrease the size of chat messages for easier reading.

    ![Chat Panel Settings](assets/chat-panel-settings.png)
    *Chat panel settings showing options to turn off notifications and adjust the text size of chat messages.*

## Manage your chat messages

You can interact with the messages to keep conversations organized and up to date. Reply to messages, react with emojis, edit messages after sending, or delete them when they are no longer needed.

To manage a message in the chat:

1.  Hover over the message to view available actions.

1.  Select the required action.

| **Action** | **Description** |
|----|----|
| **React** | Add an emoji reaction to acknowledge or respond to a message without sending a new chat message. |
| **Reply** | Respond to a specific message. The reply includes a reference to the original message for better context. |
| **Edit** | Update a message after sending it. The edited message replaces the original message in the chat. |
| **Delete** | Remove your message from the chat. A "Message deleted" label appears to maintain the flow of the conversation. |

## Send private messages

The **Private** tab allows you to communicate directly with other participants during a session without sharing messages in the public chat.

To start a private conversation:

1.  Select the **Private** tab.

1.  Select a participant from the list.

    ![Private Chat Tab](assets/private-chat-tab.png)
    *The Private tab shows a one-to-one conversation between a learner and another participant.*

1.  Type your message and select **Send**.

A private conversation opens with the selected participant. Messages are visible only to you and that participant.

>[!NOTE]
>
> Private chat availability depends on session settings. If the Instructor disables private chat, you cannot start or participate in private conversations.
