# View the Session dashboard

The session dashboard in Live Hub provides insights for Learner participation, engagement, and session performance. It helps Instructors review how learners interacted during a session and evaluate its effectiveness.

The dashboard consolidates key metrics such as attendance, participation, and interactions, enabling better analysis and decision-making for future sessions.

## Key benefits

* **Centralized visibility**: Monitor learner participation, attendance, and interactions from a single dashboard.

* **Engagement insights**: Understand how learners interact during the session and identify engagement patterns.

* **Performance analysis**: Evaluate session effectiveness using participation and interaction data.

* **Data-driven improvements**: Use insights from the dashboard to enhance future sessions and learning outcomes.

## Access the Session dashboard

Follow these steps to view the session dashboard for a Live Hub session:

1.  Log in to Adobe Learning Manager as an Instructor.

1.  Select **Past sessions** from **Your sessions**. This opens the **Your Past Sessions** page.

    ![Past Sessions Navigation](assets/past-sessions-navigation.png)
    *Select Past sessions from Your sessions to open the Your Past Sessions page.*

1.  Open the course for which you want to check the session analytics. <br> The **Session Overview** page appears.

1.  Navigate to the **Live hub** section and select **View analytics page**. <br> The **Analytics** dashboard opens with detailed insights for the selected session.

    ![Session Analytics Url Option](assets/session-overview-page.png)
    *Select View analytics page in the Live hub section to open the Analytics dashboard.*

## What insights are available

The session dashboard presents session data across multiple tabs, each focusing on a specific aspect of learner participation and performance. Together, these views help Instructors analyze attendance, engagement levels, and interaction patterns for the session.

![Session Dashboard Insights Overview](assets/session-dashboard-insights-overview.png)
*The session dashboard presents data across the Session summary, Interactions, Participant activity, and Reports tabs.*

The following tabs are available in the session dashboard:

| **Tab** | **Description** |
|----|----|
| **Session summary** | Provides a high-level overview of live and recording performance, including session duration, the number of enrolled and joined learners, average attended duration, attendance over time, participant engagement, and recording insights such as total views and average view duration. |
| **Interactions** | Displays participant engagement by interaction method, organized into Polls, Quiz, Breakouts, and Other interactions, enabling analysis of how learners took part in interactive activities. |
| **Participant activity** | Provides participant-wise details, including attendance and interaction data, to help track individual involvement. |
| **Reports** | Allows you to download session analytics and data for offline review. |
