# Understand the closed captions

Closed captions are generated automatically during a Live Hub session and update continuously as attendees speak. Captions appear in a dedicated display area and are displayed in the language selected by the Instructor in **Room settings**.

Both Instructors and participants can view captions. Each attendee can show or hide captions independently without affecting the caption settings for other attendees.

Only Instructors can change the caption language. Participants can only view captions in the language chosen by the instructors. Participants cannot change the language of the captions.

## How Live Hub determines the caption language

Live Hub automatically selects the caption language based on the following priority order:

1. **Course language:** Live Hub uses the course language if it is supported for captions. For a multilingual course, if the current course instance uses a language that doesn't support closed captions, Live Hub selects the language of the first course instance that supports closed captions. View [Supported languages in ALM](../../migrated/languages-supported.md) for more information.
1. **Account language:** If the course language is not supported, Live Hub checks the account language and uses it if supported.

>[!NOTE]
>
>If neither the course language nor the account language is supported, Live Hub selects English as the caption language. Also, the Captions are turned off by default and must be enabled manually.

## How do closed captions work

In a Live Hub session, closed captions are generated automatically. Captions display in a dedicated panel and update continuously as participants speak. Both Instructors and Learners can view captions.

Each participant can show or hide captions as they prefer. Changing this setting does not affect other participants.
