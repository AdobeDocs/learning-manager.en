# About the Chat panel in Live Hub

The Chat panel in Live Hub enables real-time communication between Instructors and Learners during live sessions. It supports public discussions, private conversations, and structured question handling, helping Instructors manage interactions efficiently while keeping learners engaged.

## Key benefits

* **Improved interaction**: Enables real-time communication between Instructors and learners.

* **Structured discussions**: Separate tabs for Everyone, Private, and Questions keep conversations organized.

* **Efficient question handling**: AI-powered assistance helps Instructors identify and respond to questions quickly.

* **Moderation control**: Instructors can manage and maintain a productive discussion environment.

* **Contextual communication**: Reply and mention features ensure clarity in conversations.

## Chat panel tabs

The Chat panel includes multiple tabs to help manage different types of conversations during a Live Hub session.

* **Everyone**: Use this tab to send and view messages visible to all participants. AI also detects learner questions from messages posted in this tab.

* **Private**: Use this tab to have one-to-one conversations with specific participants during the session.

* **Questions**: This tab displays questions identified by AI from the public chat. Instructors can review, group, and respond to questions efficiently.

>[!NOTE]
>
> The **Questions** tab is available only to Instructors.
