# Manage closed captions as an Instructor

Closed captions display spoken content as on-screen text, making a Live Hub session easier to follow, for example, while you're presenting, responding to participant questions, or working in a noisy environment. As an Instructor, you can manage your own closed captions from the room **More actions** menu.

This article explains how to select the caption language, display closed captions, and change their appearance during a Live Hub session.

## Select the caption language

Select the language used to display captions during the session. All participants see captions in the selected language.

>[!NOTE]
>
>AI-powered features are available only for courses in English. If the course language is set to another language, the **Captions** tab indicates that AI-powered features are unavailable.

To select the caption language:

1. Select **More actions** from the control bar.
1. Select **Settings**.

   The Room settings dialog opens.

1. Select **Captions**.
1. Select a language from the Captions display language drop down menu.
1. Select **Done**.

## Display closed captions

Display closed captions during a Live Hub session to view real-time transcription of spoken content.

To enable closed captions:

1.  Select **More options (⋯)** from the control bar.

1.  Select **Captions**.

1.  Enable **Show captions**. Closed captions display at the bottom of the interface.

    ![Enable Closed Captions Instructor](assets/enable-closed-captions-instructor.png) *Enable Show captions to display the closed captions in the session.*

## Change the appearance of closed captions

You can customize the appearance of closed captions during a session to improve readability based on your viewing needs.

To change caption appearance:

1.  Select **More options (⋯)**.

1.  Select **Captions**.

1.  Select one of the following options:

    1.  **Font size**: Select a size for the text of the closed captions. The available options are **Small**, **Medium**, and **Large**.

    1.  **Caption style**: Select a color combination. The available combinations are **Black on White**, **Yellow on Black**, **White on Black**, **Dark on Yellow**, and **Yellow on Blue**.

    ![Closed Captions Appearance Instructor](assets/closed-captions-appearance-instructor.png)
    *Select Font size to change the size of the text displayed in the captions.*
