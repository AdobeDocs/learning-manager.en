# Sample prompts for Adobe Learning Manager learners

## Overview

You have to connect your AI client first. View [Connect your AI client](/help/migrated/learners/feature-summary/connect-ai-client-to-alm-learner.md). Each prompt maps to a tool in the [Learner tools reference.](/help/migrated/learners/feature-summary/learner-tools-reference.md)

## Enrollments

| Prompt                               | Tool       |
|------------------------------------------|----------------|
| What courses am I enrolled in?           | Get enrollment |
| Which of my courses are about to expire? | Get enrollment |

## Search

| Prompt                              | Tool |
|-----------------------------------------|----------|
| What leadership courses are available?  | Search   |
| Show security training available to me. | Search   |

## Knowledge

| Prompt                                              | Tool     |
|---------------------------------------------------------|--------------|
| What does supply chain risk management mean in FedRAMP? | Answer agent |
| Explain the requirements in my compliance course.       | Answer agent |

## Learning paths

| Prompt                                                      | Tool               |
|-----------------------------------------------------------------|------------------------|
| Help me find a set of courses to upskill in project management. | Generate learning path |
| Save this learning path.                                        | Save learning path     |
