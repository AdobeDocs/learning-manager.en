# View and add comments to a course

If you are the course creator, select the **Comments** panel in your project to view comments and reply to them.

1. **Open the Comments panel**: select **Comments** from the toolbar. The comment panel displays the comments provided by the reviewer.

2. You can mark the comments as resolved or edit or delete the comments.

3. Make the required changes and **Save** the project.

4. Select **Share** from the toolbar to update the latest link.
