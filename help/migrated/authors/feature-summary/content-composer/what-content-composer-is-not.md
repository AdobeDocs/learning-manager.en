# What Adobe Learning Manager Content Composer is not

To set accurate expectations before you begin:

- Content Composer does not support branching or adaptive learning paths. Courses follow a linear Lessons > Topics structure.

- The end-of-lesson quiz supports only multiple-choice questions and True/False questions in the current beta. Additional question types are on the roadmap.

## What's next

When you're ready to begin, see [Create a course with Content Composer](#create-course) for the full step-by-step workflow.

**Try the app**. Open [**Content Composer**](https://contentcomposer.adobe.io/) and follow along with the step-by-step guide.

If you run into issues, contact support or post your queries on the [Adobe Learning Manager community](https://community.adobe.com/adobe-learning-manager-466).
