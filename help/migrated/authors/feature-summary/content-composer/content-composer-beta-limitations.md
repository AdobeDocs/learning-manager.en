# Adobe Learning Manager Content Composer beta limitations

A complete list of current Content Composer beta constraints, with descriptions and workarounds where available.

## Current limitations

The following table covers all known constraints in the current beta release.

| **Limitation**                                                | **Description**                                                                                                                                                                                                                   | **Workaround**                                                                                                                                                |
|---------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Outline editing is conversational only**                    | You cannot select a lesson or topic on the canvas to rename, reorder, or delete it. All outline changes must be made through the assistant chat panel.                                                                            | Ask the assistant: "Rename Lesson 2 to 'Password Hygiene'" or "Move topic 1.3 to Lesson 2."                                                                   |
| **Outline hierarchy is fixed**                                | The course structure is fixed as Lessons > Topics. You cannot create sub-topics, additional hierarchy levels, or custom structures.                                                                                               | Use the available components to add depth within a topic.                                                                                                     |
| **Outline cannot be edited directly after course generation** | Once a course is generated, topic names and lesson names remain part of the outline structure. You must return to outline-level conversations to change them. You cannot rename them by selecting a heading in the Course editor. | Ask the assistant in the Course editor: "Rename Lesson 3 to 'Incident Response'."                                                                             |
| **Assessment types: MCQ and True/False only**                 | The current beta supports only multiple-choice questions (**MCQ**) and True/False questions. Other assessment types are not available.                                                                                            | - |
| **Question banks are not available**                          | You cannot import or manage a bank of pre-authored questions.                                                                                                                                                                     | Build additional questions conversationally: "Add two more questions to the quiz for Lesson 1."                                                               |
| **Knowledge checks are not graded**                           | Knowledge checks embedded within lessons are not graded. Only end-of-lesson quiz assessments are graded and recorded.                                                                                                             | Use quizzes (not knowledge checks) for any assessment that must produce a completion or score record.                                                         |
| **Conversational actions limited to supported capabilities**  | The assistant can discuss and brainstorm freely, but actual course modifications are limited to features supported by the product. Requests to generate unsupported content structures or formats may not succeed.                | If a request does not work, ask the assistant to explain what it can do instead.                                                                              |
| **Document-restricted generation**                            | When **Restrict output to content in files** is enabled, Content Composer generates content from the uploaded source documents only. It does not introduce information beyond those sources.                                      | Disable the toggle to allow the AI to supplement with general knowledge.                                                                                      |
| **Collaboration features are evolving**                       | Share for Review and Commenting and Share for Learners are both under active development. Implementation details may change before general availability.                                                                          | Use **Copy link** to share a preview link for informal review. For co-editing, coordinate turns with collaborators. Simultaneous co-editing is not supported. |
| **In-product assistant is not a product-help system**         | The conversational assistant is designed for course editing tasks, like generating and modifying content. Responses to product-usage questions may be unreliable because this behavior is not yet explicitly designed.            | For how-to questions, use the existing help documentation rather than asking the in-product assistant.                                                        |
