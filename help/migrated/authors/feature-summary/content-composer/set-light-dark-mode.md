# Set light mode or dark mode for the course

<!--Select **light/dark** mode in the toolbar to toggle between modes. Content Composer updates the canvas to reflect the selected mode.-->

Select [!UICONTROL Account menu] > [!UICONTROL Apply theme] > light or dark mode. Content Composer updates the canvas to reflect the selected mode.
